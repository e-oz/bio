Origin story / 2004It started with
a mobile phone.+

My passion for programming started at school.

In 2004, I started earning money by making websites.

One of my first tools was an FTP editor — a tool for uploading, removing, and editing files (mostly PHP scripts). It was designed for use on a mobile phone (in 2004, not every Russian youngster had a computer, so “mobile-first” was more than a motto for us).

The most interesting part: I had just three hours of computer access to develop it. I wrote the rest of the code using the editor itself — yes, from a mobile phone.

This tool helped dozens of people create their first websites (or WAP sites).

It was challenging but extremely rewarding.
